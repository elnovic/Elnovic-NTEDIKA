# Elnovic Ntedika — site personnel

Site portfolio d'une page (FR/EN) : profil, projets IA, parcours, événements, compétences, certifications et contact.

- `index.html` : toute la page (HTML, CSS et JS dans un seul fichier)
- `portrait.jpg` : photo du profil

Mise en ligne avec GitHub Pages : Settings → Pages → Source « Deploy from a branch », branche `main`, dossier `/ (root)`.
